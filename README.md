# REALTYAI Landing Page

Upload these files directly into the root of the `realtyai` repository on GitHub:

- `index.html`
- `style.css`
- `main.js`
- `favicon.svg`
- `robots.txt`
- `sitemap.xml`
- `README.md` (optional)

GitHub Pages must use the `main` branch and the `/ (root)` folder.

Open the project site at: https://ihorluchak.github.io/realtyai/

Important: open the site normally in Safari/Chrome, not in Reader/Reading mode. Reader mode removes CSS and JavaScript, so tabs and buttons cannot work there.
