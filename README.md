# REALTYAI Landing Page

Готова статична версія для GitHub Pages.

## Важливо
Усі файли мають бути завантажені **в корінь репозиторію**, без папок:
- index.html
- style.css
- main.js
- favicon.svg
- robots.txt
- sitemap.xml
- README.md

У `index.html` вже прописані правильні шляхи до `style.css`, `main.js` та `favicon.svg`.
