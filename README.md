# REALTYAI — фінальна responsive-збірка

## Що зроблено

Ця збірка зберігає мобільну версію як базову та додає окремі правила для планшетів і Desktop.

Передбачено:

- адаптацію для мобільних екранів;
- адаптацію для планшетів у портретній та альбомній орієнтаціях;
- обмежену ширину контенту на великих екранах;
- коректне стискання колонок без горизонтального переповнення;
- читабельніші заголовки та текстові блоки;
- захист від накладання scroll-анімацій на Desktop;
- збереження перемикача «Рієлтор / Асистент»;
- збереження `.nojekyll` для GitHub Pages.

## Як завантажити

1. Розпакуйте архів.
2. Замініть старий `index.html` у репозиторії цим файлом.
3. Залиште `.nojekyll` у корені репозиторію.
4. Зачекайте оновлення GitHub Pages.
5. Перевірте сайт у режимі інкогніто або після очищення кешу.

## Рекомендована фінальна перевірка

- Телефон: 390 px.
- Планшет: 768 px та 1024 px.
- Ноутбук: 1280 px та 1440 px.
- Desktop: 1920×1080.
- Chrome та Safari.
- Портретна й альбомна орієнтації.
- Перемикач «Рієлтор / Асистент».
- Усі кнопки, посилання, скрол і анімації.

## Важливе обмеження

Структура та код перевірені статично. Повний реальний тест у Chrome/Safari на фізичних пристроях у цьому середовищі не виконувався, тому остаточну перевірку після публікації потрібно зробити у браузері.
